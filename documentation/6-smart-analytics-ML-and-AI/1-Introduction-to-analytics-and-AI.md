# 🧠 Introduction to Analytics and AI

## Exam-focused summary

## Core idea

This module is very introductory.
The main goal is to distinguish:

* **AI**
* **Machine Learning**
* **Deep Learning**

and to explain how ML helps move from:

* **ad hoc analysis**
* to **data-driven, scalable decision-making**

---

## 1) AI vs ML vs Deep Learning

### **AI**

AI is the broad discipline.

It is about:

* machines acting autonomously
* machines solving problems in ways that resemble human thinking or acting

### **ML**

Machine learning is a **toolset inside AI**.

It is used to:

* learn from data
* generate predictive insights
* make repeated decisions at scale

### **Deep Learning**

Deep learning is a **type of ML**.

It is especially useful for **unstructured data**, such as:

* images
* speech
* video
* text

### Key exam point

> **AI is the discipline; ML is the toolset; Deep Learning is a subtype of ML.**

---

## 2) BI vs ML

The transcript makes a very important distinction.

### **Business Intelligence (BI)**

BI is usually:

* backward-looking
* based on historical data
* used for dashboards and reports

### **Machine Learning**

ML is:

* forward-looking
* predictive
* designed to make repeated decisions automatically

### Main contrast

* **BI** explains what happened
* **ML** helps predict what is likely to happen next

---

## 3) Why ML matters

The transcript’s real message is not that ML is magical.
It is that ML allows decision-making to **scale**.

A human analyst may look at data and suggest:

* raising the price of one product
* changing policy in one region

But that does not scale well across:

* every product
* every region
* every minute or second

### Main point

ML makes predictive decision-making:

* repeatable
* scalable
* automated

### Best exam takeaway

> **ML scales predictive insights and operational decision-making.**

---

## 4) Deep learning use cases

Deep learning is highlighted as the branch of ML that works well on unstructured data.

Typical examples:

* image classification
* object detection
* speech recognition
* natural language processing

### Important idea

For very complex problems, deep learning can sometimes perform better than humans.

This helped:

### Why this example matters

It shows ML being used for:

## 6) From ad hoc analysis to data-driven decisions

The bike rental example is about moving from manual analysis to automated prediction.

### Ad hoc analysis

A business owner might manually inspect:

* rental duration trends
* station-by-station variation
* day-of-week patterns
* hour-of-day patterns

That can be slow and may not lead to scalable action.

### ML approach

Use a model, such as **linear regression**, to predict future bike demand from historical patterns.

### Main idea

ML automates pattern detection and forecasting better than repeated manual analysis.

---

## 7) ML options on Google Cloud

The lesson gives **three levels of ML usage** on Google Cloud.

### **1. Custom models**

For advanced users who want full control.

Example:

* build custom models with libraries like **TensorFlow**
* use **Vertex AI**

Best for:

* data scientists
* advanced ML users
* teams needing custom behaviour

---

### **2. AutoML**

For users who want custom models but with much less ML expertise.

Best for:

* limited ML knowledge
* no need to write TensorFlow manually
* building tailored business models more easily

---

### **3. Pretrained APIs**

Google also offers ready-to-use pretrained models.

These do **not** require you to bring your own training data.

Examples mentioned indirectly:

* Vision API
* Natural Language API

Best for:

* immediate use
* standard ML tasks
* replacing manual user input with ML-based capabilities

# 🧪 Interview version

If they ask for the difference between AI and ML, a clean answer is:

> AI is the broad field concerned with building intelligent machines, while machine learning is a specific approach within AI that allows systems to learn patterns from data and make predictions or decisions without being explicitly programmed for every case.

If they ask for the main business value of ML, a strong answer is:

> The main value is scalability. ML allows predictive insights and decision-making to be automated across many cases, much faster and more consistently than manual analysis.
